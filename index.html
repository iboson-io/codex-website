Your engineering guide becomes the review

Most tools check generic best practice. Codex also checks the rules your company wrote down, and tells the developer which clause they broke.

  • Turn an engineering guide into rules. Requirements are lifted word for word from your document, never paraphrased.
  • Approved versions are locked. Last quarter's scan still shows what the standard said last quarter.
  • Exceptions expire. A waiver needs an approver and an end date, and it's shown in every report.
  • Different rules for different places. Set them per organisation, team, repository or folder.
  • Map findings to SOC 2 and ISO 27001 controls for your auditor.

Questions

Does my code leave my machine?

Not in VS Code with AI off, which is the default. If you turn AI on, code is sent only to the AI provider you choose, with your own key. Self-hosted installs can run with no outbound network at all.

Do I have to use AI?

No. The 824 built-in rules are deterministic and run without any AI provider. AI review is an optional extra layer.

Who pays for the AI?

You do, directly to your provider, using your own key. Codex doesn't mark up AI usage. Rescans reuse earlier AI results for code that hasn't changed, so you only pay for what's new.

What happens if a paid plan or licence lapses?

You drop to the free tier. Scanning keeps working and your data stays. Codex never switches off your security checks because of billing.

Which Git providers are supported?

GitHub, GitLab, Bitbucket and Azure DevOps, for both repository scans and pull request review.
