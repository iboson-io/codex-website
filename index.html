FREQUENTLY ASKED QUESTIONS

Good questions.
Straight answers.

Read the product guide
Does my code leave my machine?

Not in VS Code with AI off, which is the default. If you turn AI on, code goes only to the provider you choose, using your own key. A self-hosted installation can run with no outbound network.

Do I have to use AI?

No. The rule engine is deterministic and runs without an AI provider. AI review is an optional additional layer.

Does Reyo learn from my code?

Yes. When AI review finds a defect, Reyo can turn it into a deterministic rule, prove it against your code, and add it to your organisation’s rules once an admin approves it. From then on it runs on every scan with no AI call. Rules learned from your code are never shared with other organisations.

Who pays for the AI?

You pay your provider directly using your own key. Reyo does not mark up AI usage. Rescans reuse earlier AI results for unchanged code, so you only pay for what is new.

What happens if my plan or licence lapses?

You drop to the free tier. Scanning keeps working and your data stays. Security checks are not switched off because of billing.

Which Git providers are supported?

GitHub, GitLab, Bitbucket and Azure DevOps support repository scans and pull request review. On GitHub, you can also reply to a review comment to ask a follow-up question.
