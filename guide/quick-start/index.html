REYO / QUICK START

Start where you write code.

Begin with local analysis. Add collaboration and governance when your team needs them.

01

01 · Request early access

Contact iBoson to get the VS Code extension or CLI and the current setup instructions. Public package names and install commands are not provided on the source site.

02

02 · Analyse locally

In VS Code, findings appear as you save. Local analysis needs no server, account or network. AI is off by default.

03

03 · Add pull request review

Connect GitHub, GitLab, Bitbucket or Azure DevOps for inline review comments. On GitHub, reply to comments to ask follow-up questions.

04

04 · Introduce a CI gate

Fail builds on severity, score or a breached company requirement. Use SARIF 2.1.0 output with your existing security dashboards. The standards-gate example below is the command published on the product site.

standards-gateINTERACTIVE EXAMPLE
$code-analyzer standards-gate --repository api --fail-on high
